# Editor runes migration (#260)

Target: `sveltekit`. This checklist covers all components under `src/lib/components/editor/**`. Shared/navigation components are complete under #259; SVG-rendering components remain a separate group under #261. Preserve store contracts, edit-history boundaries, selections, imported assets, shared links, downloads and FMG synchronization. Migrate in reviewable batches without a simultaneous state-model redesign.

## Batch 1: bound controls and layer actions

Thirteen components now use runes mode: Switch, General/Inscription inputs, Stroke/Striped options, Above/Layered/Outside/Divided controls, field Type/Size selectors, layer Controls and Restore. Typed `$props` and `$bindable` declarations retain the existing parent bindings. Layer actions use event attributes and still stop propagation. Their array props are generic, removing the previous `any` declarations.

The parent editor still owns plain legacy objects. Inscription and stroke inputs therefore use [function bindings](https://svelte.dev/docs/svelte/bind) to replace their bound object when a field changes, notifying the parent without depending on deep proxies. A direct nested-binding conversion produced runtime non-reactive-binding warnings; the explicit setters remove those warnings without suppressions or changes to the parent state model.

`test:editor-controls` runs in browser CI. Nine cases verify one undo step per action, unchanged history length during undo/redo, name/zoom/Restore and reload, inscription text/font/style controls, stroke/stacking/division options, stripe-mode defaults, charge layering/outside placement, field type/pattern size, and clone/reorder/remove for ordinary, charge and inscription layers without toggling the parent section. The same tests pass on the unchanged pre-batch baseline. Existing suites retain JSON imports, shared/copy links, FMG race/cancellation, SVG/PNG/JPEG downloads and metadata, saved resources, and production/offline coverage.

For before/after rendering evidence, run the focused suite with `EDITOR_CONTROLS_RESULTS=/tmp/editor-controls.json`. It captures metadata, exported SVG and a rasterized PNG for six edited artworks. This batch matches the baseline's metadata and PNG bytes exactly; exported SVGs also match after normalizing only the random instance numbers in shield/division/inscription IDs and their references. All other SVG content remains unchanged.

## Batch 2: previews and selection

Nine more components use runes: EditorItem, EditorCharge, EditorDivision, EditorField, EditorLine, EditorOrdinary, EditorPattern, EditorShield and EditorTincture. Preview lists use `$derived`, search/category state uses `$state`, and selectable values retain typed `$bindable` contracts. EditorField replaces its bound object through function bindings, preserving extra division properties and notifying the legacy parent. Palette persistence remains an effect that writes only after colors change; opening a panel does not persist recovered defaults. The main editor and SVG renderer remain unchanged.

The derived search lists also fix an existing inconsistency: changing a preview input could replace filtered charge/shield results with a full category while leaving the search text in place. Results now remain filtered as preview inputs or translations change. Uploaded-charge catalog changes invalidate both category lists and searches, including deletion. Search syntax and category-reset behavior are preserved.

`test:editor-selection` adds eight browser cases. Seven behavior-preservation cases pass on the unchanged baseline and this branch: shield search/category selection and reload; division/ordinary/line selection with nested field edits; pattern/semy selection; translated charge search; palette editing/restoring; and custom vector/raster selection, reload and removal. The eighth case demonstrates the old stale-search bug on the baseline and passes after migration. Artwork edits create one undo step with stable undo/redo; search/category and palette operations do not add artwork-history entries. Runtime binding warnings are treated as failures.

`EDITOR_SELECTION_RESULTS=/tmp/editor-selection.json` captures six representative exports. Shield, division, ordinary, pattern, semy and charge artwork match the baseline's metadata and PNG bytes exactly, and SVGs match after normalizing only random instance IDs. Existing regression suites cover JSON/shared links, SVG/PNG/JPEG exports, FMG synchronization and production/offline behavior.
